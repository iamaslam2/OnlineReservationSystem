# Online Reservation System

A Java-based GUI application that allows users to book and cancel reservations.

## Features
- User Login
- Ticket Reservation
- Automatic PNR Generation
- Booking Confirmation
- Ticket Cancellation
- Input Validation

## Technologies Used
- Java
- Java Swing
- SQLite Database
- JDBC
